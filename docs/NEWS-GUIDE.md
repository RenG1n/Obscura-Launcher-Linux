# Правила обновления новостей Obscura

Этот документ обязателен при каждом выпуске новой версии. Если новости редактирует другая нейросеть или разработчик, сначала прочитайте этот файл.

## Обязательное правило выделения

- `src/renderer/scripts/news-data.js` — единый источник записей для страницы «Новости».
- Массив `OBSCURA_NEWS` всегда отсортирован от самой новой версии к самой старой. Новая запись добавляется строго в начало массива.
- **Выделяется только первая запись (`OBSCURA_NEWS[0]`)**: акцентная рамка/фон и бейдж «ПОСЛЕДНЕЕ ОБНОВЛЕНИЕ».
- Все остальные записи всегда обычные, нейтральные карточки. Не ставьте им `featured: true`; renderer намеренно определяет выделение по позиции, поэтому старые флаги не смогут подсветить предыдущий релиз.
- Не удаляйте старые новости и не меняйте их порядок без причины. После добавления новой записи предыдущая автоматически теряет выделение.

## Что обязательно сделать при каждом релизе

1. Изучить фактические изменения в исходном коде, тестах и пользовательских сценариях. Не придумывать функции и не описывать незавершённые возможности как готовые.
2. Добавить в начало `OBSCURA_NEWS` запись с точными `version`, `date`, `title`, кратким `lead` и полным списком `items`.
3. Включить все значимые изменения, которые увидит пользователь: новые функции, исправления, улучшения, ограничения и важные инструкции. Использовать теги `new`, `fixed`, `better`. Писать понятно, конкретно и по-русски.
4. Указать точную версию и дату. Заголовок и lead должны сразу объяснять суть выпуска; пункты не должны скрывать важные изменения за общими словами.
5. Синхронизировать `CHANGELOG.md`, версию в `package.json` (если это новый релиз), README и документацию. Удалить устаревшие или противоречащие описания функций.
6. Проверить, что только первая карточка выделена, остальные нейтральны, и что точка у пункта «Новости» продолжает работать для новой версии.
7. Запустить `npm test` и проверить синтаксис затронутых JavaScript-файлов.

## Формат записи

```js
{
  version: '1.0.2',
  date: 'ДД месяц ГГГГ',
  badge: 'ПОСЛЕДНЕЕ ОБНОВЛЕНИЕ',
  title: 'Obscura Release 1.0.2 — краткая тема релиза',
  lead: 'Краткое и точное описание главного результата обновления.',
  items: [
    { tag: 'new', text: 'Что добавлено и как этим пользоваться.' },
    { tag: 'fixed', text: 'Какая проблема исправлена и что изменилось для пользователя.' },
    { tag: 'better', text: 'Что улучшено.' }
  ]
},
```

Не добавляйте поле `featured`: renderer сам подсвечивает исключительно первую запись. Бейдж также показывается только у первой записи.
