# Changelog

## Release 1.1.0 — 9 ноября 2026

- **Визуальный мод**: переключатель справа от кнопки «Запустить игру». Режим фиксирует Minecraft 1.21.11 + Fabric и запускает игру в отдельной папке `visual/` (как у сборок; versions/libraries/assets остаются общими). Версия и загрузчик заблокированы в интерфейсе и на стороне главного процесса; после выключения выбор возвращается. Пока режим включён, появляется кнопка 🧩 с папкой модов визуального мода. `.jar` мода вшивается в сборку из `visual-mod/`; при запуске копируется в папку мода, устаревшая копия удаляется, чужие моды не трогаются. Опционально докачивается Fabric API (`visual-mod/manifest.json`).
- **Загрузчики — исправления установки**:
  - NeoForge: поддержка Minecraft с годовой нумерацией (26.1, 26.1.2…); «рекомендуемой» теперь считается новейшая стабильная сборка, а не просто последняя.
  - Forge: полный список сборок из индекса Maven; корректный адрес установщика для старых версий (1.7.10 и т. п.); нестандартные имена версий (`1.7.10-Forge…`) распознаются как установленные — больше нет переустановки при каждом запуске.
  - Fabric/Quilt: один общий установщик вместо двух копий; при первой ошибке загрузки остальные потоки останавливаются; удалённые библиотеки восстанавливаются при следующем запуске.
  - Forge/NeoForge: установщик запускается потоково (нет обрыва по `maxBuffer`), отмена завершает всё дерево процессов, в окне видно, что делает установщик; если библиотеки установленной сборки пропали — установщик запускается повторно. Сбой восстановления никогда не блокирует запуск уже установленной сборки.
  - `npm run doctor`: проверка серверов NeoForge, Quilt и Modrinth; `--loader fabric:1.21.11` реально ставит загрузчик во временную папку.
- **Linux**: сборки AppImage, .deb и .tar.gz (`npm run dist:linux`), иконки PNG, поиск Java в `/usr/lib/jvm`, `~/.sdkman`, `~/.jdks`, `~/.minecraft/runtime`, автозапуск лаунчера после закрытия игры (опция «Закрывать лаунчер»), тексты ошибок без привязки к Windows. CI гоняет тесты на Windows и Ubuntu.
- **Тесты**: 180+ (новые — загрузчики, визуальный режим, реальный `renderer.js` на подставном DOM).

## Release 1.0.1 — 30 октября 2026

- **Discord Game Activity**: Windows-приложение собирается как `Obscura Launcher.exe` для обнаружения в «Зарегистрированных играх». Без Rich Presence, Application ID, кнопок и таймеров; динамическое добавление версии в название не поддерживается обычным обнаружением процесса.
- **Автозакрытие лаунчера**: опциональное полное завершение Obscura после запуска игры и повторный запуск после закрытия Minecraft (Windows packaged build).
- **Microsoft**: убран автоматический повторный запуск входа из обработчика запуска игры; пользователь запускает авторизацию явным действием. В рамках одного входа браузер открывается только один раз.
- **Темы**: исправлен контраст карточек новостей, выделенного релиза и вспомогательного текста в светлой теме.
- **Версия**: обновлены номер версии в интерфейсе и документации.

Предыдущие версии: [docs/changelog](docs/changelog).

## Release 1.0.0

- Окно **«Добавить моды»** вместо встроенной панели в карточке сборки: каталог Modrinth с популярными модами, поиском, 14 категориями, сортировкой и страницами; вкладка «Установлено» с удалением.
- Каталог строго по сборке: Fabric — моды Fabric, Forge — Forge, NeoForge — NeoForge, Quilt — Quilt и Fabric. Серверные моды не показываются.
- Исправлено: сборки с версией «последний релиз» / «последний snapshot» не находили моды — теперь версия определяется автоматически (и в каталоге, и при установке).
- Исправлено: сообщения об ошибках Modrinth, импорта модпаков и сборок больше не заменяются общим «Внутренняя ошибка лаунчера».
- Уведомления (тосты) показываются поверх модальных окон.
- **Новости**: только самая новая запись выделяется акцентной рамкой и бейджем; после выхода следующей версии прежняя карточка автоматически становится обычной. Точка у «Новостей» горит, пока новая запись не открыта.
- Тесты: 151 (новые — каталог, Quilt, категории, алиасы версий, IPC).
