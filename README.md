Obscura — Minecraft Java Launcher
Release 1.1.0 · MIT · Electron · Windows и Linux
Открытый лаунчер для Minecraft: Java Edition с отдельными сборками, каталогом модов Modrinth и импортом модпаков. Интерфейс на русском языке, тёмная и светлая темы.
Возможности
Запуск игры
Любые релизы и snapshot из официального манифеста Mojang, а также псевдонимы «последний релиз» и «последний snapshot».
Установка и запуск одной кнопкой; отмена, повторная попытка при сбоях сети (до 3 раз), запуск без сети, если игра уже установлена.
Выбор объёма памяти (RAM) с проверкой по свободной памяти компьютера.
Автоустановка Java: нужная версия (8, 17, 21, 25) скачивается сама (Eclipse Temurin), проверяется SHA-256 и выбирается под версию игры. Ручная установка и удаление — в настройках.
Аккаунты
Вход Microsoft без ввода пароля в лаунчер (device-code), несколько аккаунтов с быстрым переключением.
Локальный офлайн-профиль для одиночной игры и серверов без проверки лицензии.
Токены шифруются средствами ОС (`safeStorage`) и вырезаются из логов.
Сборки
Отдельные профили: у каждой свои моды, миры, конфиги, ресурс-паки, шейдеры и скриншоты; общие файлы игры не скачиваются повторно.
Создание, переименование, дублирование и удаление сборки, быстрый доступ к её папкам, запуск из карточки.
Моды
Загрузчики: Fabric, Forge, Quilt и NeoForge (выбор версии загрузчика, установка с официальных серверов и проверкой контрольных сумм).
Окно «Добавить моды»: каталог Modrinth строго под загрузчик и версию Minecraft сборки (у Quilt также моды Fabric), поиск, 14 категорий, сортировка, страницы; серверные моды скрыты.
Установка одной кнопкой вместе с обязательными зависимостями, проверка SHA-1; вкладка «Установлено» с удалением.
Импорт модпаков Modrinth (.mrpack) по ссылке или из файла: сборка создаётся с нужной версией игры и загрузчиком, все файлы скачиваются с проверкой хэшей, настройки (`overrides`) распаковываются безопасно.
Внешний вид
Тёмная и светлая темы, свой цвет акцента, фона и боковой панели, положение навигации.
Свой фон главной страницы (любая картинка, перетаскивание или выбор файла) и встроенные фоны.
Страница «Новости» со списком изменений; выделяется только самая новая версия, предыдущие автоматически отображаются обычными карточками.
Надёжность и безопасность
Нумерованные ошибки `OBS-xxx` с причиной и решением; отчёты сохраняются в папке ошибок (список кодов).
Изоляция интерфейса (`contextIsolation`, `sandbox`, без `nodeIntegration`), узкий preload-API, проверка отправителя каждого IPC-вызова.
Загрузки только с разрешённых https-хостов, в том числе при перенаправлениях; проверка контрольных сумм; защита от небезопасных путей в архивах.
180+ автотестов, самопроверка `npm run doctor`.
Визуальный мод (1.1.0)
Переключатель справа от кнопки «Запустить игру». Включён — запускается Minecraft 1.21.11 + Fabric в отдельной папке (`visual\`), версию и загрузчик менять нельзя: поля заблокированы, а главный процесс отклоняет такие изменения.
Пока режим включён, рядом с переключателем видна кнопка 🧩 — она открывает папку модов визуального мода.
Выключили — снова можно выбирать версию и загрузчик, прежний выбор сохранён.
Файл мода кладётся в папку `visual-mod/` проекта (см. `visual-mod/README.txt`) и вшивается в сборку; перед запуском лаунчер копирует его в папку мода и, если нужно, докачивает Fabric API.
Быстрый старт
Нужны Node.js 22 LTS и интернет.
```bash
npm install            # зависимости (Electron, @xmcl/core, @xmcl/installer, prismarine-auth, electron-builder)
npm start              # запуск лаунчера
npm test               # автотесты
npm run doctor         # проверка библиотек, серверов Mojang/Microsoft/Fabric/Forge/NeoForge/Quilt, Java и памяти
npm run dist           # сборка под вашу систему (Windows или Linux)
npm run dist:win       # Windows: dist/Obscura-Setup-<версия>.exe и Obscura-Portable-<версия>.exe
npm run dist:linux     # Linux: dist/Obscura-<версия>-linux-x64.AppImage, .deb, .tar.gz
```
Готовые скрипты «сделать всё»: `build-windows.bat` (двойной щелчок) и `./build-linux.sh`.
Linux. Запуск `.AppImage`: `chmod +x Obscura-*.AppImage && ./Obscura-*.AppImage`. На Ubuntu 24.04+ из-за ограничения AppArmor на пользовательские пространства имён может понадобиться `./Obscura-*.AppImage --no-sandbox`; пакет `.deb` этой проблемы не имеет (sandbox настраивается при установке). Данные лежат в `~/.config/Obscura/`. Для сохранения входа Microsoft нужна связка ключей (gnome-keyring / KWallet); без неё работает локальный профиль. Для Minecraft нужны графические драйверы с OpenGL.
Windows-установщик надёжнее собирать на Windows, AppImage/.deb — на Linux. Кросс-сборка возможна (`dist:win` на Linux требует Wine), но не проверялась.
Проверка установки игры на реальной машине (скачает игру во временную папку, ~0.5 GB):
```bash
npm run doctor -- --install 1.21.8
# проверка установки загрузчика (в временную папку): fabric:1.21.11, quilt:1.21.1, forge:1.20.1, neoforge:21.1
npm run doctor -- --loader fabric:1.21.11
```
Если `npm install` в PowerShell пишет «running scripts is disabled», выполните один раз `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` (или используйте `npm.cmd` вместо `npm`).
Сборка встраивает иконку в `.exe`, поэтому билдер скачивает свои инструменты и создаёт символические ссылки. Если `npm run dist` падает с «Cannot create symbolic link» — включите «Режим разработчика» Windows (Параметры → Для разработчиков) или запустите PowerShell от администратора.
Как пользоваться модами
Откройте Сборки → + Новая сборка, выберите версию Minecraft и загрузчик (Fabric, Forge, Quilt или NeoForge).
В карточке сборки нажмите 🧰 Добавить моды. Окно покажет самые популярные моды именно для этой сборки; ищите по названию, выбирайте категорию и сортировку, листайте страницы.
+ Добавить ставит мод и его обязательные зависимости. Список и удаление — на вкладке Установлено.
Готовый модпак: ⬇ Импорт модпака → ссылка на страницу модпака на modrinth.com, прямая ссылка на `.mrpack` или файл с диска.
▶ Играть в карточке сборки запускает игру с этими модами.
Выбранные во «Версии игры» на главной загрузчик и версия относятся к общей папке игры (Windows: `%APPDATA%\Obscura\minecraft`, Linux: `~/.config/Obscura/minecraft`); у сборок своя папка `<данные Obscura>/builds/<id>`.
Вход Microsoft (настройка своей сборки)
Используется Microsoft device-code: лаунчер показывает код и открывает `microsoft.com/link`, пароль в лаунчер не вводится.
По умолчанию `prismarine-auth` использует общедоступный идентификатор приложения Xbox. Для собственной сборки для других людей
зарегистрируйте приложение в Azure и получите одобрение Mojang, затем задайте его перед запуском:
```powershell
$env:OBSCURA_MS_CLIENT_ID = "ваш-client-id"; npm start
```
Discord Game Activity
Лаунчер собирается как `Obscura Launcher.exe`, чтобы Discord мог обнаруживать его через Зарегистрированные игры. Это обычная Game Activity по обнаруженному процессу — без Discord Rich Presence, Application ID, кнопок и таймеров.
Запустите Obscura Launcher.
В Discord откройте Настройки пользователя → Зарегистрированные игры и добавьте запущенный `Obscura Launcher.exe`, если Discord не обнаружил его автоматически.
Включите Отображать текущую активность в статусе в настройках конфиденциальности активности.
Discord сам формирует название активности из обнаруженного/зарегистрированного приложения. Автоматически подставить в это название текущую версию лаунчера одним лишь обнаружением процесса нельзя. В этой сборке имя процесса фиксировано как `Obscura Launcher`; версия (`1.0.1` и т. п.) не добавляется. Для динамического текста вида `Obscura Launcher 1.0.1` потребовалась бы отдельная интеграция с Discord, то есть уже не чистое обнаружение Game Activity.
Фон
В качестве фона подходит любое изображение, которое открывает Chromium (PNG, JPEG, WebP, GIF, BMP, AVIF, SVG): выбор файла в «Настройки → Своя картинка», правая кнопка на «Изменить фон» или перетаскивание на главную. Лаунчер уменьшает картинку до 2560 px, сохраняет как WebP, а главный процесс повторно проверяет содержимое файла.
Структура проекта
Файл	Назначение
`src/main/main.js`	Окно Electron: `contextIsolation`, `sandbox`, `nodeIntegration: false`, запрет навигации/окон/разрешений
`src/preload/preload.js`	Единственный мост в страницу: замороженный объект `window.obscura`
`src/main/ipc.js`	Все IPC-каналы: проверка отправителя, валидация, ошибки без стеков
`src/main/game.js`	«Играть»: версия → установка → загрузчик → аккаунт → Java → RAM → запуск; отмена; логи
`src/main/adapters/xmcl.js`	Обёртка над `@xmcl/installer` и `@xmcl/core` (аргументы запуска берутся из JSON Mojang)
`src/main/versions.js`	Версии из манифеста Mojang, кэш на диске
`src/main/loaders.js`	Fabric, Forge, Quilt, NeoForge: список версий и установка
`src/main/runtime.js`, `java.js`	Автоустановка и поиск Java
`src/main/builds.js`	Сборки: профили со своими папками
`src/main/modrinth.js`	Каталог Modrinth (`browse`, `search`), установка модов с зависимостями, список установленных
`src/main/mrpack.js`, `zip.js`	Импорт `.mrpack`; собственный строгий ZIP-ридер
`src/main/net.js`	HTTPS-клиент: белые списки хостов, лимиты размера, контрольные суммы, повторы
`src/main/auth.js`	Вход Microsoft (`prismarine-auth`), офлайн-профиль, шифрование токенов
`src/main/errors.js`	Каталог ошибок `OBS-xxx` и классификация
`src/main/{settings,ram,backgrounds,logger}.js`	Настройки, проверка RAM, свой фон, лог с маскированием токенов
`src/renderer/*`	Интерфейс; `scripts/news-data.js` — текст страницы «Новости»
`scripts/doctor.js`	Самопроверка на реальной машине
`src/main/visual.js`	Визуальный мод: отдельная папка, копирование .jar, Fabric API
`visual-mod/`	Сюда кладётся .jar визуального мода (попадает в сборку)
`build/icon.ico`, `build/icon.png`	Иконки приложения (Windows / Linux)
`test/*.test.js`	Автотесты
Данные пользователя: Windows — `%APPDATA%\Obscura\`, Linux — `~/.config/Obscura/` (настройки, фон, `minecraft/`, `builds/`, `visual/`, `runtime/`, `logs/launcher.log`, `errors/`, `auth/`).
Что проверено, а что нет
Автотестами (с заглушками вместо сети и библиотек) проверены: валидация настроек, оркестрация запуска, IPC-граница, загрузчики, каталог модов и установка с зависимостями, импорт `.mrpack`, чтение ZIP, шифрование токенов, маскирование токенов в логах. Интерфейс окна модов и новостей проверен в Chromium с подставными данными.
Подтверждено на Windows владельцем проекта: `npm install`, `npm run doctor`, `npm start` (окно открывается).
Пока не подтверждено на реальных серверах: скачивание и запуск игры, вход Microsoft, сборка `.exe`, работа каталога Modrinth и импорта модпаков против настоящего API. Нашли ошибку — откройте issue и приложите последние строки `%APPDATA%\Obscura\logs\launcher.log` (токены в нём замаскированы).
Известные ограничения
Java скачивается автоматически (Eclipse Temurin; Windows/Linux/macOS x64 и arm64 — по ответу Adoptium). Без интернета нужна Java, установленная вручную.
Forge: рекомендуемая и последняя сборки из `promotions_slim.json`, а также более старые сборки из индекса Maven (если он доступен). NeoForge поддерживает Minecraft 1.20.2+ и новые версии вида 26.x.
Загрузчики сами восстанавливают удалённые библиотеки при следующем запуске (Fabric/Quilt — докачкой, Forge/NeoForge — повторным запуском установщика).
Каталог модов — только Modrinth (не CurseForge); добавляются только моды, не шейдеры и ресурс-паки.
Для официальных онлайн-серверов нужен лицензионный Microsoft-аккаунт; офлайн-профиль работает только в одиночной игре и на серверах без проверки.
Google Fonts грузятся из интернета (без сети — системный шрифт).
`@xmcl/core` и `@xmcl/installer` закреплены на 2.15.1 и 6.1.2: последние версии этих пакетов опубликованы с зависимостью `workspace:`, которую npm не устанавливает. `prismarine-auth`, `electron` и `electron-builder` указаны как `latest` — после установки сохраните `package-lock.json` в репозитории.
